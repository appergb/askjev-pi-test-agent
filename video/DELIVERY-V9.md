# askJEV 宣传片动效优化版

V9 参考用户提供的 25970939042-1-16.MP4，对 V8 增加动画与过渡。保留原文案、产品内容、镜头顺序、真实截图和音乐，画面时长仍为 50.48 秒、1920×1080、25 fps。

## 动效改进

- 8 处场景过渡，包括侧向推移、圆形遮罩和彩色光带，每处 0.32–0.56 秒。
- 修复前后截图错峰滑入，配合轻旋转、弹性缩放、反光与运费位置描边；停稳后进行适度推近。
- 回归结果弹性落位，六个盾牌从分散位置聚合并描边。
- 点击按钮后展开终端，段尾终端缩向品牌位置，衔接片尾。
- 片尾标语分段入场，项目地址横向揭示，最后保持完整阅读画面。

## 文件

- askjev-motion-1080p.mp4：最终视频。
- askjev-v9-editable.zip：可编辑源码、依赖锁文件、字体许可、素材和制作记录。
- askjev-motion.zh.srt：可选字幕，与 V8 时序保持一致。
- cover.png：从本版成片提取的封面。
- validation-v9.json：导出、画面、音频与独立工程检查记录。

## 编辑

解压源文件包后进入 studio：

```bash
npm ci
npm run dev
npm run lint
npm run render
```

主合成为 AskJEV-Motion。镜头位于 src/v9；Transitions.tsx 控制过渡，Proof.tsx 控制截图运动，Verified.tsx 控制回归结果，Launch.tsx 控制按钮与终端展开，End.tsx 控制片尾。默认导出 ../exports/askjev-v9-1080p.mp4。

使用依赖锁定版本提供的 Chrome Headless Shell。V8 成片和工程保留，可直接对比或回退。参考拆解与时序设计见 MOTION-V9.md。
