# askJEV 宣传片 V9 动效优化

本轮依据用户提供的 25970939042-1-16.MP4 优化 V8，仅调整动画与场景衔接。产品内容、文案、镜头顺序、50.48 秒画面时长、25 fps、原音乐与素材保持一致。

## 参考观察

参考片为 640×360、25 fps，约 50.52 秒。通过全片 32 点缩略图、33–39 秒和 41.6–46.8 秒的每秒 5 帧序列检查，确认以下动作：

- 画面快速到位后缓停，局部元素错峰入场。
- 页面与卡片通过推近、拉远、缩入中心建立衔接。
- 33 秒后以彩色光效覆盖画面，随后出现网格和卡片拼贴；37 秒后收为中心操作面板。
- 41.6 秒后按钮反馈接页面展开，45 秒后页面收缩并转入品牌标识。

V9 借用上述节奏与运动方式，继续使用 askJEV 自有的产品画面和品牌。

## 修改

| 位置 | 新动效 |
| --- | --- |
| 场景交界 | 加入 8 处推移、圆形遮罩和短光带过渡，每处 8–14 帧，即 0.32–0.56 秒 |
| 页面对照 | 两张真实截图左右错峰进入，伴随 3.5 度以内旋转、弹性缩放与反光扫过；停稳后最多推近 14%，聚焦运费断言位置 |
| 价格与标题 | 标题逐字揭示，金额从底部进入；矩形描边逐步标记原页面的运费行 |
| 回归结果 | 大号结果弹性落位，六个盾牌从分散位置聚合到结果行，再完成勾选描边 |
| 接入关系 | 点击按钮后，通过中心遮罩展开同一终端；段尾终端缩至品牌位置 |
| 片尾 | 品牌承接终端收束，标语分段入场，项目地址横向揭示，末段保持完整可读 |

## 时序与内容约束

基础场景仍为 145、93、112、115、35、184、56、100、143、57、115、107 帧，合计 1262 帧。为避免新增转场改变音乐节拍，给前一个场景增加对应过渡长度，再由 TransitionSeries 重叠同等帧数；原场景超过末帧后只保持该帧。各场景的开始时间与 V8 一致。

copy.json 与 V8 逐字节一致；页面截图、品牌素材与音乐未替换。金额没有插值成未经实测的中间值，只有原值文字的位移。过渡不延长成片，不新增旁白、产品能力或性能主张。

## 工程

V9 使用独立 src/v9、RootV9.tsx、index-v9.ts、render-v9.mjs，保留 V8。

```bash
cd studio
npm run dev:v9
npm run render:v9
```

主合成 AskJEV-Motion。Transitions.tsx 控制场景过渡，Proof.tsx、Verified.tsx、Launch.tsx 与 End.tsx 控制本轮主要改动。导出后重新核对全部帧解码、已知重复画面问题、关键连续帧、文字可读性和音轨一致性。实际结果见 validation-v9.json。
